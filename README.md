# Sunset Bail Bonds — макети головної сторінки

Три дизайн-варіанти нової головної сторінки [sunsetbailbonds.com](https://sunsetbailbonds.com/)
для погодження з партнером. Кожен — самодостатній `.html`: вся розмітка, стилі,
скрипти й зображення (base64) в одному файлі, без збірки й залежностей.

**Живі посилання:** https://regdev-git.github.io/sunsetbailbonds/

| Посилання | Стиль |
|---|---|
| [`sunsetbailbonds-home-v1/`](sunsetbailbonds-home-v1/) | Картковий стиль: інсет-hero з превʼю наступного слайду, bento-рядки, скляні стат-чіпи поверх фото. Гротеск. |
| [`sunsetbailbonds-home-v2/`](sunsetbailbonds-home-v2/) | Full-bleed hero, чергування «фото / текст», плитки округів з кольоровим оверлеєм. Серифи. |
| [`sunsetbailbonds-home-v3/`](sunsetbailbonds-home-v3/) | Редакційний стиль: сторінка як біла скруглена «картка» на сірому тлі, hero з вирізаним кутом під CTA, пронумеровані картки. Гротеск. |

## Запуск локально

```bash
python3 -m http.server 4173
```

Відкрити <http://localhost:4173>.
